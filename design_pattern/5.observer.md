# Observer Pattern

## ما هو الـ Observer Pattern؟

الـ **Observer Pattern** هو Design Pattern بيخلي **Object** يبلّغ مجموعة من الـ **Objects** التانية لما يحصل عنده تغيير أو Event.

بالمصري:

> **"حاجة حصلت، بلّغ كل الناس اللي مهتمة بيها."**

## المكونات

* **Subject:** الـ Object اللي بيحصل فيه التغيير.
* **Observer:** الـ Object اللي عايز يتبلغ لما التغيير يحصل.
* **attach():** إضافة Observer.
* **notify():** إبلاغ كل الـ Observers.

## مثال

في E-commerce، لما Order يتعمل:

```text
Order Created
     |
     ├──> Send Email
     ├──> Send Notification
     └──> Write Log
```

الـ `Order` مش محتاج يعرف تفاصيل الـ Email أو Notification أو Log.

هو بس بيعمل:

```php
foreach ($observers as $observer) {
    $observer->update($this);
}
```

## ليه نستخدمه؟

* يقلل الـ coupling بين الـ objects.
* يخلي إضافة behaviors جديدة أسهل.
* كل Observer مسؤول عن حاجة واحدة.

## Laravel Example

فكرة الـ Observer موجودة في Laravel في:

```text
Event
  ↓
Listeners
  ├── SendEmail
  ├── SendNotification
  └── LogActivity
```

## Interview Answer

> **Observer Pattern allows an object to notify multiple dependent objects when its state changes, without tightly coupling the object to them.**
