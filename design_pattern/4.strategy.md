# Strategy Pattern

## ما هو الـ Strategy Pattern؟

الـ **Strategy Pattern** هو Design Pattern بيسمح لك إنك يكون عندك **أكتر من طريقة لتنفيذ نفس الـ behavior**، وتقدر تختار الطريقة المناسبة وقت التشغيل.

بالمصري:

> **"عندي أكتر من طريقة أعمل بيها نفس الحاجة، واختار الطريقة اللي محتاجها."**

## المكونات

- **Strategy:** Interface بيحدد الـ behavior المشترك.
- **Concrete Strategies:** كل Class بيطبق طريقة مختلفة.
- **Context:** الـ Class اللي بيستخدم الـ Strategy.

## مثال

عندك Shipping، وطرق الشحن مختلفة:

```text
Shipping
   |
   ├──> StandardShipping
   ├──> ExpressShipping
   └──> InternationalShipping
```

كلهم بيعملوا نفس الحاجة:

```php
interface ShippingStrategy
{
    public function calculate(float $weight): float;
}
```

لكن كل Strategy عندها طريقة مختلفة للحساب.

## ليه نستخدمه؟

بدل ما نعمل:

```php
class ShippingService
{
    public function calculateCost($type, $weight)
    {
        if ($type === 'standard') {
            return $weight * 10;
        }

        if ($type === 'express') {
            return $weight * 25;
        }

        if ($type === 'international') {
            return ($weight * 50) + 100;
        }

        return 0;
    }
}

$service = new ShippingService();

echo $service->calculateCost('standard', 5);
echo $service->calculateCost('express', 5);
echo $service->calculateCost('international', 5);

```

نخلي كل طريقة في Class منفصل.

ده بيقلل الـ **if/else** ويخلي إضافة Strategy جديدة أسهل.

```php
interface ShippingStrategy
{
  function calculateCost(float $weight): float;
}


class Standard implements ShippingStrategy
{
  function calculateCost(float $weight): float
  {
    return $weight * 10;
  }
}


class Express implements ShippingStrategy
{
  function calculateCost(float $weight): float
  {
    return $weight * 25;
  }
}


class International implements ShippingStrategy
{
  function calculateCost(float $weight): float
  {
    return ($weight * 50) + 100;
  }
}


class ShippingService{
  function __construct(private ShippingStrategy $strategy, private float $weight){}
  function calculateCost(){
    return $this->strategy->calculateCost($this->weight);
  }
}
```

## Interview Answer

> **Strategy Pattern defines a family of interchangeable algorithms or behaviors, encapsulates each one in a separate class, and allows the application to switch between them at runtime.**
